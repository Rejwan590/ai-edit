# Punch-in
Use on a key claim, number or emotional beat. Ease in over about 200 ms, hold, ease out over about 400 ms. Do not stack with screen shake. Skip if the shot is already tight. Check that captions stay inside the frame at full zoom (the engine blocks it if not).
